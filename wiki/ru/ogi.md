# Порт OGame Infinity на 0.84

> Задача: [#130 «Port OGame Infinity to 0.84»](https://github.com/ogamespec/ogame-opensource/issues/130).
> Реализация — в папке [`ogi/`](../../ogi/README.md): это браузерное расширение, а
> не модификация движка.

## Обзор

[OGame Infinity](https://ogameinfinity.com/) (OGI) — расширение для современного
OGame: оно читает страницы сообщений, собирает базу шпионских отчётов, результатов
экспедиций, боёв, переработки и активности игроков и рисует поверх игры панели
аналитики.

Порт на 0.84 — это порт на игру, в которой **нет никакого API**: ни атрибутов
`data-raw-*`, ни JSON, ни id у элементов, ни постраничного вывода сообщений. На
страницах 0.84 есть только локализованный текст и вёрстка 2003 года — то есть ровно
то, для чего в OGI существовали ветки кода для старых версий игры. Поэтому порт
сохраняет подход OGI (шаблоны + классификация по тексту) и отбрасывает всё, что
относится к современной игре.

## Что портировано

| Возможность OGI | Реализация в 0.84 |
|---|---|
| Таблица шпионских отчётов (добыча, пропорции, нужный транспорт) | `parsers/spy.js`, `analyze/index.js` |
| База шпионских отчётов и история цели | `lib/store.js`, `lib/collect.js` |
| Анализатор экспедиций (12 семейств результатов, размер, находки) | `parsers/texts.js` |
| Анализатор боёв (добыча, потери, обломки, итог) | `parsers/battle.js` |
| Анализатор переработки | `parsers/texts.js` |
| Учёт транспорта (торговли) | `parsers/texts.js` |
| История планет и игроков («сталкинг») | `parsers/galaxy.js`, `lib/store.js` |
| Отслеживание активности | `parsers/galaxy.js` |

## Что не портировано (и почему)

В 0.84 нет Форм Жизни, классов игроков, офицеров, предметов, магазина тёмной
материи и современных кораблей — соответствующим возможностям OGI просто нечего
читать:

- Формы Жизни: сообщения об открытиях, артефакты, исследования форм жизни;
- классы игроков (Собиратель / Генерал / Исследователь) и обзор империи, доступный
  только с офицером;
- предметы/инвентарь, магазин, предложения тёмной материи;
- современные корабли (Pathfinder, Reaper, Crawler) и современные правила грузоподъёмности зондов;
- сторонние сервисы OGI (тепловая карта активности PTRE, внешние симуляторы, ссылки
  на mmorpg-stat.eu) — у них нет конечных точек для 0.84;
- чисто клиентские удобства, привязанные к современной вёрстке (уведомления
  браузера, фильтры `#messagewrapper`, пересчёт часовых поясов).

## Архитектура

```
страницы игры ─► parsers/ ─► lib/collect.js ─► lib/store.js ─► analyze/ ─► lib/panel.js
  (HTML/текст)   (шаблоны)    (дедупликация)   (localStorage)   (итоги)   (вёрстка 0.84)
```

- **`tools/build-data.js`** извлекает из самой игры то, что нужно парсерам:
  `src/data/loca.js` (все строки из `game/loca/<lang>_<lang>/`, 7 языков, с
  подстановкой PHP-констант вроде `GID_RC_METAL`) и `src/data/units.js` (стоимости
  и параметры из `game/core/techs.php`). Ни одна игровая строка или цена не
  зашита в расширение вручную.
- **`lib/templates.js`** превращает строку локализации в регулярное выражение
  (`"Resources on #1"` → `Resources on (…)`) — так расширение читает числа из
  готового отчёта.
- **`lib/html.js`** — устойчивый к ошибкам сканер: вёрстка 0.84 нарушает
  собственные правила (тела сообщений содержат вложенные таблицы, подсказки
  галактики — целые HTML-документы внутри атрибутов, а одинокая кавычка в апострофе
  ломает кавычки в подсказке активности шпионского отчёта). Сканер учитывает
  кавычки и восстанавливается так же, как это делает браузер.
- **`lib/store.js`** хранит по одной базе на хост и вселенную в `localStorage`,
  с дедупликацией по id сообщения и ограничениями размера.
- **`lib/panel.js`** рисует панель обычными HTML-строками в старом дизайне
  (`table.header`, `td.c`), поэтому аналитика выглядит как родная страница игры.

Подробности, описание формул и структура файлов — в
[README расширения](../../ogi/README.md).

## Тестирование

```bash
node --test "ogi/tests/**/*.test.js"     # из корня репозитория
```

Набор тестов использует golden-снимки самого репозитория
(`testing/golden/<lang>/*.html`, см. [GoldenPagesTest](GoldenPagesTest.md)) как
фикстуры: парсеры проверяются на настоящих отрендеренных страницах семи языков, а
тест упаковки загружает все скрипты в порядке манифеста в песочнице — так же, как
это делает браузер.
