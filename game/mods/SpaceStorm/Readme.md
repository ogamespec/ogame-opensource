# Космический Шторм (Space Storm)

![bg](img/bg.png)

Модификация добавляет глобальное периодическое событие **«Космический Шторм»**, которое на время меняет базовую механику игры, а также новую планетарную постройку **«Стабилизатор Реальности»**, способную частично компенсировать негативные эффекты шторма на своей планете.

Мод создан как **тестовый полигон** для проверки бонусной панели, добавления новой постройки в игру и работы глобальных модификаторов базовой логики (задача [#172](https://github.com/ogamespec/ogame-opensource/issues/172)).

> **Внимание:** это не сбалансированный игровой контент, а демонстрационный мод для механизмов движка. Числовые значения подобраны для наглядности и могут меняться.

## Новая постройка

**Стабилизатор Реальности** (`GID_B_REALITY_STAB = 57384`) — высокотехнологичное сооружение, которое не борется со штормом, а гармонизирует его энергию, превращая хаос в контролируемую выгоду.

| Параметр | Значение |
|---|---|
| Стоимость | 50 000 металла · 125 000 кристалла · 50 000 дейтерия |
| Множитель стоимости | **3.0** за уровень |
| Требования | Лаборатория (ур. 3+), Терраформер (ур. 1+) |
| Доступность | Строится **только во время активного шторма** |

### Базовый эффект

Каждый уровень даёт **+0.5% к выработке энергии** на планете за счёт стабилизации энергосетей.

### Запечатление шторма

При завершении строительства уровня на планете «запечатлевается» тип шторма, активный в этот момент. В дальнейшем Стабилизатор компенсирует именно эти типы шторма (см. [эффекты Стабилизатора](#эффекты-стабилизатора-реальности)). Снос постройки снимает запечатлённые эффекты. Эффекты распространяются и на луну рядом с планетой.

## Событие «Космический Шторм»

- Событие запускается в очереди (`SpaceStorm`) и обновляется **каждый час**.
- При каждом обновлении формируется новый шторм по вероятностной схеме, зависящей от силы предыдущего:

| Сила предыдущего шторма | Исход |
|---|---|
| 0 эффектов | 75% — слабый шторм (1 эффект), иначе — тишина |
| 1 эффект | 50% — средний шторм (2 эффекта), иначе — тишина |
| 2 эффекта | 25% — сильный шторм (3 эффекта), иначе — слабый шторм или тишина |
| 3 эффекта | 75% — тишина, иначе — слабый шторм или тишина |

- Тип шторма — набор случайных бит из набора ниже (один или несколько одновременно).
- О начале, усилении, ослаблении и окончании шторма игрокам отправляется сообщение через `BroadcastMessage`.

## Эффекты шторма

Активный шторм может одновременно содержать один или несколько эффектов. Каждый эффект — **глобальный** (влияет на всю вселенную).

| # | Название | Механика |
|---|---|---|
| 0 | **Субпространственная Турбулентность** | Скорость всех флотов в Галактике снижена на 30%–50% (время полёта увеличено). |
| 1 | **Скачок в Подпространстве** | 5% шанс, что флот мгновенно прибудет к цели; 1% шанс, что флот заблудится и вернётся через 1–2 часа. |
| 2 | **Полярное Искажение Щитов** | Броня всех кораблей и обороны снижена на 20%, щиты усилены на 30%. |
| 3 | **Квантовая Нестабильность Двигателей** | Расход дейтерия для полётов увеличен на 100%; выработка дейтерия повышена на 25%. |
| 4 | **Хроно-шпионский сбой** | Отчёты шпионажа приходят с задержкой 1–5 минут; уровень шпионажа всех игроков понижен на 2. |
| 5 | **Энергетический Коллапс** | Выработка энергии падает на 40%; при отрицательном балансе с шансом 10% в час случайная постройка/исследование замораживается. Заморозка автоматически снимается при восстановлении энергии. |
| 6 | **Гравитационная Аномалия Защиты** | Защитный барьер планет поглощает часть урона (щиты усилены на 10%). |
| 7 | **Сигнатура Материи** | 20% добытых ресурсов конвертируется в один случайный тип ресурса. |
| 8 | **Провал в Связи** | Временно отключается «Транспорт» между собственными планетами. |
| 9 | **Реверберация Атаки** | При успешной атаке атакующий теряет 5% от стоимости флота. |

## Эффекты Стабилизатора Реальности

Стабилизатор смягчает негатив конкретного шторма **на своей планете**, но только пока соответствующий тип шторма активен и был запечатлён на планете. Сила контр-эффекта растёт с уровнем постройки.

| Тип шторма | Контр-эффект Стабилизатора |
|---|---|
| Субпространственная Турбулентность | +3% скорости флотов, отправленных с планеты, за уровень. |
| Скачок в Подпространстве | −0.4% шанса мгновенного прибытия и −0.08% шанса заблудиться за уровень. |
| Полярное Искажение Щитов | Искажение брони/щитов ослаблено на 3% за уровень. |
| Квантовая Нестабильность Двигателей | −8% расход дейтерия и +3% к его добыче за уровень. |
| Хроно-шпионский сбой | −0.4 мин задержки отчётов и +1 уровень шпион-защиты за каждые 2 уровня. |
| Энергетический Коллапс | −4% штрафа к энергии за уровень; отключения построек не происходят. |
| Гравитационная Аномалия Защиты | Защитный барьер ослаблен на 1% за уровень. |
| Сигнатура Материи | −2% конверсии ресурсов за уровень. |
| Провал в Связи | Транспорты между своими планетами доступны несмотря на шторм. |
| Реверберация Атаки | −0.4% потерь атакующего за уровень. |

> **Примечание к реализации.** Боевые контр-эффекты (Полярное искажение и Гравитационная аномалия) применяются на уровне **фронтенда боевого движка** — они масштабируют базовые статы юнитов в данных конкретного боя (см. «Боевые эффекты» ниже), поэтому влияют на бой целиком, а не только на обороняющуюся сторону.

## Установка

Мод подключается через админ-панель (`pages_admin/admin_mods.php`), как и любой другой мод репозитория:

1. Добавьте мод в список активных (`modlist`).
2. Активируйте его — `install()` добавит нужные колонки и запустит событие шторма.

Поддерживаемые языки: **русский, английский, немецкий**.

### Боевые эффекты (фронтенд боевого движка)

Боевые эффекты шторма реализованы **без изменения бэкенда движка** (`battle_engine.php`). Вместо этого добавлен хук `battle_unit_stats`, вызываемый во фронтенде (`GenBattleSourceData`, файл `game/core/battle.php`) непосредственно перед сериализацией базовых статов юнитов в данные боя. Хук масштабирует статы только для текущего боя, не меняя глобальные параметры игры.

### Основные хуки мода

| Хук | Назначение |
|---|---|
| `update_queue` | Генерация нового шторма каждый час + тик Энергетического Коллапса. |
| `add_bonuses` | Вывод иконки шторма в бонусную панель. |
| `bonus_prod` | Модификаторы выработки (дейтерий, энергия, стабилизатор). |
| `bonus_fleet_cons` / `bonus_fleet_speed` | Топливо и скорость флотов. |
| `prod_post_process` | Конверсия «Сигнатура Материи». |
| `battle_unit_stats` | Боевые статы (Полярное искажение, Гравитационная аномалия). |
| `battle_post_process` | Реверберация атаки после боя. |
| `fleet_available_missions` | Запрет/разрешение транспорта («Провал в Связи»). |
| `add_db_row` | Скачок в подпространстве, задержка шпионажа. |
| `can_build` / `build_end` | Доступность и запечатление Стабилизатора. |
| `page_infos` | Отображение запечатлённых штормов на странице информации о постройке. |

## Тестирование

Юнит-тесты мода находятся в корневом каталоге `testing`:

- `testing/SpaceStormTest.php` — тесты чистой логики (модификаторы производства, топлива, скорости и боевых статов).
- `testing/SpaceStormDbTest.php` — тесты против in-memory БД (боевые контр-эффекты, Сигнатура Материи, заморозка очереди).

Запуск:

```bash
vendor/bin/phpunit --filter SpaceStorm
```
